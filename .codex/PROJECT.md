# NU-DESIGN

## Project Overview

NU-DESIGN is a premium graphic design studio website built with modern web technologies.

The website must communicate professionalism, elegance, creativity and trust.

This is NOT a template-based website.

Everything should feel custom-made, clean and premium.

---

# Main Goal

Build a fast, elegant and scalable website that represents NU-DESIGN as a premium creative studio.

The final website should look comparable to high-end creative agencies.

---

# Technology Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Shadcn/UI (Base UI)
- Motion
- Lucide Icons
- next-themes

---

# Design Philosophy

Minimal.

Elegant.

Premium.

Modern.

Lots of whitespace.

Excellent typography.

Smooth animations.

Pixel-perfect spacing.

Responsive on every device.

Accessibility first.

Performance first.

---

# Coding Standards

- Always use TypeScript.
- Always use functional components.
- Keep components small and reusable.
- Avoid duplicated code.
- Use semantic HTML.
- Prefer composition over large components.
- Never hardcode repeated values.
- Keep the code clean and readable.
